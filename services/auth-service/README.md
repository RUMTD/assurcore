# auth-service (Java / Spring Boot)

## Rôle
Authentification et gestion des rôles (Client, Gestionnaire, Administrateur). Émet et vérifie les
JWT utilisés par tous les autres services pour valider les droits d'accès.

## Statut
À implémenter en Phase 2 (TDD). Voir `docs/uml/02-diagramme-classes.md` pour le modèle de données
et `docs/adr/002-choix-langages-par-service.md` pour la justification du choix Java.
